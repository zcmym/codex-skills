# PPT Master — Advanced Mode

Use this as the advanced visual-production alternative to `ppt-standard`. It does not replace factual verification or source traceability.

## Workflow
1. **Creative brief:** define audience, objective, key message, tone, format, duration, and constraints. Inspect supplied materials and templates.
2. **Narrative architecture:** establish the thesis, audience journey, section arc, and slide-by-slide message before styling.
3. **Visual system:** define palette, typography, spacing/grid, image direction, chart language, diagram grammar, and reusable components.
4. **Storyboard:** specify each slide's role, takeaway, evidence, visual concept, and layout.
5. **Production:** use native editable PowerPoint objects wherever feasible. Retain editable text and data labels when using SVG or raster visuals.
6. **Reconstruction:** distinguish content to preserve from styling to reinterpret. Reuse protected assets only when supplied or licensed.
7. **Visual QA:** render every slide; inspect individual slides and full-deck rhythm; fix hierarchy, contrast, alignment, cropping, overflow, and chart consistency.
8. **Delivery:** provide editable deck, sources, and a note describing non-editable visuals or rendering limitations.

## Advanced design principles
- Use a distinctive, coherent visual concept; avoid style for style's sake.
- Vary composition deliberately across cover, section dividers, evidence, diagrams, and conclusions.
- Make technical diagrams precise: label flows, boundaries, units, and interfaces.
- Use data-driven charts with explicit scales and honest baselines.
- Maintain accessibility and sufficient contrast; never convey meaning by color alone.
- Cite external sources and assets.
- Never claim visual verification unless every slide has actually been rendered and inspected.

## Handoff
- Routine class or project decks route to `ppt-standard`.
- Use this skill for major creative direction, custom identity, reference-deck reconstruction, or premium visual polish.
- Do not silently expand slide count, subject matter, or deliverables.
